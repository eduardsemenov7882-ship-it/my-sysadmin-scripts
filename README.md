## Описание проекта
Проект демонстрирует автоматизацию задач системного администрирования в Ubuntu Linux. Он включает Bash-скрипт мониторинга системных ресурсов, запуск приложения в Docker, настройку RAID1 и LVM, обратный прокси Nginx с HTTPS и управление приложением через systemd.

## Структура проекта

- `script.sh` — Bash-скрипт мониторинга системных ресурсов.
- `sample_output.txt` — пример вывода скрипта.
- `homework2/Dockerfile` — сборка Docker-образа.
- `homework2/script.sh` — скрипт мониторинга внутри контейнера.

## Проверенные компоненты

### Мониторинг
Скрипт использует команды `free -h`, `df -h` и `uptime` для отображения состояния системы.

### Docker
Контейнер `my-app` запускается на порту `8080`.

### RAID1
Состояние массива проверяется командой `cat /proc/mdstat`. Получен результат `[2/2] [UU]`, означающий, что оба диска активны.

### LVM
Логический том `vg_data/lv_logs` смонтирован в `/mnt/logs`.

### Nginx и HTTPS
Конфигурация проверяется командой `sudo nginx -t`. Запрос `curl -kI https://localhost` возвращает `HTTP/1.1 200 OK`.

### systemd
Сервис `my-app` включён в автозапуск и находится в состоянии `active (running)`.

### Журналы
Работу сервиса можно проверить через `journalctl -u my-app`. Запросы Nginx записываются в `/var/log/nginx/access.log`, ошибки проверяются в `/var/log/nginx/error.log`.

## Важно
Конфигурации Nginx, systemd и автоматизация развёртывания будут добавлены в репозиторий отдельно. Результаты проверок и архитектурные решения будут описаны в PDF-отчёте итогового проекта.
