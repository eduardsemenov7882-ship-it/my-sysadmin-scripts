# System Resource Monitor

## Описание
Bash-скрипт для периодического мониторинга ресурсов виртуальной машины Ubuntu.

## Что собирает скрипт
- Использование оперативной памяти с помощью free -h
- Использование дискового пространства с помощью df -h
- Время работы и нагрузку системы с помощью uptime

## Запуск
Сделайте скрипт исполняемым:
chmod +x script.sh

Запустите мониторинг:
./script.sh

Данные записываются в monitor.log каждые 10 секунд.
Для остановки нажмите Ctrl+C.

## Файлы проекта
- script.sh — скрипт мониторинга
- monitor.log — журнал измерений
- sample_output.txt — пример результата работы
